How it works

          
Core rule:

          
Basic   = IF(type = CONSULTING FEE, 0,
            IF(Wages <= MW, MW,
              IF(Wages - MW >= Wages × 50%, Wages × 50%, MW)))
PF Wage = MIN(Basic, 15000)          when PF Basis = On 15K
Er PF   = ROUND(PF Wage × 12%)       when PF Applicable = Y
Bonus   = IF(Basic > 21000, 0, ROUND(Basic × 8.33%))
HRA     = ROUND(MIN(Basic × 50% or 40%, Wages − Basic − DA − ErPF − Bonus))
Other   = Wages − Basic − DA − ErPF − HRA − FixedHeads − Bonus
GROSS   = Basic + DA + HRA + Fixed + Other + Retainer      (no Bonus, no ErPF)
Er ESIC = IF(Gross <= 21000, ROUND(Gross × 3.25%), 0)
Gratuity= ROUND(Basic × 4.81%)
CTC     = Gross + ErESIC + Gratuity + Bonus + ErPF
TOTAL WAGES = Gross + Er PF + Statutory Bonus
Take Home = Gross − Ee PF − Ee ESIC

          
Reverse mode: when Input Basis is set to Target CTC the engine runs a 16-pass iterative
            solver, and when it is set to Net Take Home it runs a 24-pass solver. Both back-solve Total Wages and
            converge within about 3 passes.

          
Formula Builder

          
Reference any column using the [KEY] format. Supported functions:

          
IF · MIN · MAX · ROUND · ROUNDUP · ROUNDDOWN · ABS · SUM ·
            AVG · AND · OR · NOT · SQRT

          
Examples:

          
[CTC] * 12
ROUND([GROSS] * 0.1, 0)
IF([BASIC] > 21000, 0, ROUND([BASIC] * 0.0833, 0))
MAX([TOTALWAGES] - [MW], 0)
[TAKEHOME] / [CTC] * 100

          
Custom columns can reference each other, in the order they were created. A circular reference safely
            returns 0.
